# Windows 普通版更新记录

以下为开发期间的更新摘要，实际功能以对应版本为准。

## Windows 0.2.11 · 2026-11-25

- 安装器首次进入可操作页面时居中，之后切换步骤保持窗口位置。
- 安装完成后启动程序与读取扩展信息时提供等待提示，期间仍可关闭安装器。
- 扩展指引分别检测 Chrome 和 Edge，检测到可用扩展时打开管理页，其余情况可复制地址。
- 安装器的扩展指引按钮保持单行。更新时由已加载的扩展打开管理页，首次添加时提供管理页地址。
- 浏览器扩展的显示版本与主程序统一。

## Windows 0.2.10 · 2026-11-25

- 安装器固定使用浅色窗口外框，保持和安装界面一致的阴影效果。
- 飞书文档下载直接进入官方用户授权，按实际授权和文档读取结果显示状态。
- 扩展 1.15.95 调整飞书音频悬浮下载，查找网页音视频和字幕移至更多下载工具。

## Windows 0.2.9 · 2026-11-25

- 扩展 1.15.94 点击飞书音频旁的悬浮按钮时自动选择对应附件，并调用飞书的原件下载。
- 扩展 1.15.93 按网页用途显示下载入口，将播放侦测放到媒体查找后，减少重复的链接抓取按钮。
- 扩展 1.15.92 精简飞书下载面板，整篇附件扫描与网页媒体查找保留在主面板，其余工具按需展开。
- 飞书缺少用户权限或被平台策略拒绝时，闪电和扩展会打开对应应用的权限页，并列出三项所需权限。
- 飞书原件工具条未打开时，悬浮下载可引导点击音频名称后继续，避免误用旁边附件的下载控件。

## Windows 0.2.8 · 2026-11-24

- 扩展 1.15.90 在音频播放器右侧显示悬浮按钮；飞书音频调用原站下载，并过滤播放预览地址。
- 扩展 1.15.89 修复缺少鼠标坐标时的悬浮报错，并识别飞书文档的自绘音频播放条。
- 扩展 1.15.88 支持通用网页音频悬浮、扫描和播放资源侦测。飞书原站附件下载继承浏览器给出的文件名。
- 飞书原始音视频可在扩展中扫描、勾选和下载。单个按原名保存，多个统一放到文档文件夹。
- 飞书明确拒绝应用授权时，显示平台错误并保留打开原文档的入口。

## Windows 0.2.7 · 2026-11-24

- 飞书文档首次使用可在新建下载中一键授权。闪电自动准备官方工具并打开授权页，授权后自动显示音视频附件清单。

## Windows 0.1.80 · 2026-11-23

- 下载列表、下载历史和扩展批量列表支持 Ctrl+A 全选当前页。列表刷新时保留仍在当前页的选中项。
- 修正合集完成数和总进度的刷新。文件抽屉会显示各视频的等待、下载和合并状态。
- 在试听前读取并显示完整波形，播放过的部分以橙色标记，右侧保持灰色。
- 合集新建下载在视频列表位置显示加载动画，读取失败时可在原处重试。
- 合集文件抽屉可为已完成的视频调整字幕样式或重新获取字幕。
- 统一网页和扩展弹窗的合集按钮比例与字体，字幕展开三角使用同一图形旋转。
- 本机下载结束或暂停后释放防睡眠请求。视频同时下载默认 5 个、最多 10 个，网站限流时提示调低。
