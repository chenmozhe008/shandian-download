## 用户安装路径

目标是在 Microsoft Edge 加载项商店和 Chrome 网上应用店分别找到扩展，点击安装，并由商店更新。Edge 也支持用户选择从 Chrome 商店安装扩展。普通商店安装不需要开启开发者模式。

- [Microsoft Edge 开发者注册](https://learn.microsoft.com/en-us/microsoft-edge/extensions-chromium/publish/create-dev-account)：需注册 Edge 开发者项目；该页面称此项目无注册费。
- [Chrome 开发者注册](https://developer.chrome.com/docs/webstore/register/)：需开发者账号和一次性注册费；具体费用及账号情况以后台为准。
- [Edge 安装扩展说明](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge)
- 现阶段应用内展示的开发者模式安装步骤仍是当前可用方式；商店链接和按钮只有上架、连接验证后才替换。

## 上架功能边界：需要先确定

Chrome 官方将协助下载 YouTube 视频列为常见拒审原因，也禁止协助未经授权地访问或下载受保护内容；[Chrome 拒审排查](https://developer.chrome.com/docs/webstore/troubleshooting)。现有扩展有网页视频提取、资源侦测和将链接交给本机应用的功能，尚未完成逐路径审核，**不能直接认定现有扩展可通过**。Edge 也要求描述准确、单一用途和尊重知识产权：[Edge 开发者政策](https://learn.microsoft.com/legal/microsoft-edge/extensions/developer-policies)。

已选方向：保留现有完整版，另做独立商店版。`browser-extension-store/` 是第一版原型，单独实现右键发送常见文件直链，不包含网页媒体扫描、Cookie 获取或自动接管；只申请 `contextMenus`、`storage` 和本机地址访问。应用运行且网关认可其真实扩展 ID 后才可能发送成功。尚未实际装入浏览器或完成商店审查，不能视为可发布版本。后续须检查所有入口、本机交互和商店最新政策，不能只隐藏按钮或换文案。实际审核结果由商店决定。

## 当前权限和代码使用位置

以下是静态初查，不代表每项权限都已证明是最小必要范围，也不代表已满足上架政策。修改前需要在 Chrome 和 Edge 实测，避免破坏已有的用户下载流程。

| 权限 | 当前可见用途 | 上架前核查 |
| --- | --- | --- |
| `downloads` | 监听浏览器下载，接管后取消；失败时可交回浏览器 | 检查用户关闭接管后的行为和失败回退 |
| `contextMenus` | 链接、视频、页面右键入口 | 对照菜单文案与实际行为 |
| `cookies` | 获取目标 URL Cookie；特定视频网站可传登录 Cookie 给本机应用 | 核查自动接管与主动操作分别读取的范围，评估按需授权及明确告知 |
| `storage` | 保存接管开关；临时侦测使用会话存储 | 确认具体保留期限与清理行为 |
| `tabs` | 获取当前标签页、监听页面及打开应用 | 核查是否可由更窄权限替代，以及标签页行为 |
| `alarms` | 本地应用连接探测、临时侦测到期 | 验证休眠、到期与禁用状态 |
| `scripting` | 按操作扫描页面链接、媒体或站点数据 | 核查触发条件、注入范围、主世界脚本与必要性 |
| `webRequest`（可选） | 用户开启后识别当前标签页媒体响应，最多 5 分钟 | 验证授权、停止、过期与权限撤销；不会因设为可选而免于最小权限要求 |
| `<all_urls>` | 接管不同站点下载并按需扫描网页；请求本机服务 | 是宽权限，必须逐功能审查能否使用按需站点授权；确认对自动接管和视频的影响 |

## 数据流初查

- 扩展使用 `127.0.0.1:6800/extension/*` 与本机应用通信，传入用户所选或浏览器接管的下载地址、来源页和部分请求头；针对登录站点，可能传入 Cookie。连接权限目前由固定扩展 Origin 限定。
- 特定页面的视频、页面链接或媒体资源可在用户操作后扫描；可选网络侦测暂存在浏览器会话存储，代码设置 5 分钟过期并尝试移除授权。
- 微信视频号分享链接的解析由用户触发，在已登录的腾讯元宝页面向其接口发起；PikPak 关联使用用户自己的登录会话。下载本身会访问用户选择的来源与相关第三方服务。
- 必须进一步核实每条路径的触发条件、Cookie 和临时文件的存储与清除、错误日志、重定向、接收方和关闭选项，才能形成准确隐私政策；不得仅凭本页断言「不收集任何数据」。

Chrome 官方明确要求处理用户数据的扩展准确披露用途，即使处理仅在本地发生也要披露；权限应限于当前功能所需的最小范围。参考 [用户数据与最小权限 FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq) 和 [Chrome 商店政策](https://developer.chrome.com/docs/webstore/program-policies/policies)。

## 提交前验证

1. 对照每项权限和站点范围形成可审核理由，并以真实行为验证隐私说明。
2. 使用不含私钥、测试数据、个人下载记录或令牌的干净 ZIP；检查 manifest、图标、版本与源码一致。
3. 获得商店实际 ID 后验证网关安全：商店扩展可连接；普通网页和未授权扩展被拒绝；本地开发版不受影响。
4. 在独立浏览器配置中验证安装、权限提示、接管、禁用、卸载、App 未运行时的回退、版本更新与站点功能。
5. 备齐中英文商店名称、简短描述、截图、支持方式和可公开访问的隐私政策；验证内容与实际支持的平台、界面语言一致。
6. 获准公开发布后再提交审核；审核通过、搜索和安装实测完成后更新应用与 README。当前尚无公开商店页面。
