## 当前进度与下一步

这是最初讨论的产品路线的整理，不是逐字还原。按用户当前选择，Windows 暂缓，先做好 Mac 和浏览器安装体验。

1. **Mac 发布：已完成一轮。** [0.18.23 正式版](https://github.com/chenmozhe008/shandian-download/releases/tag/v0.18.23)已公开 Apple 芯片和 Intel 安装包；安装包摘要与构建产物一致。主测试 45 项、3 项跳过、0 失败，跳过的流媒体测试用本地样例单独通过；Intel 在 Rosetta 测试，未在真实 Intel Mac 上测试。安装包未 Apple 公证，干净系统安装和更新仍待验证。
2. **Edge 商店：审核中。** 0.1.1 已提交，后台显示 In review，预计 7 个工作日反馈，不代表已经上架。商店版和 0.18.23 的本地右键发送已实测；商店正式安装、更新与搜索仍待审核通过后验证。
3. **Chrome 商店：已提交审核。** 0.1.1 于 2026-11-03 提交，后台显示 Pending review，审核通过后自动发布；通过前不能宣称已上架。兼容的 Mac 0.18.24 已公开。通过后须实测商店安装版，再更新应用和 README 的商店链接。
4. **稳定性与体验：持续推进。** 已修复并测试部分下载错误、云盘恢复、更新与安装回滚；断网恢复、空间不足、真实云盘和干净设备等场景仍须逐项实测。
5. **搜索与推广：基础已做，效果待验证。** 中英文名称和 README 已公开；商店搜索、真实截图、演示、英文应用界面、搜索收录和用户试用仍待完成。Star 不能作为承诺或完成标准。

近期顺序：跟踪 Chrome 和 Edge 审核 → 实测商店安装版并更新商店链接 → 扩充安装和失败恢复测试 → 改善搜索展示、文档和真实演示。商店自动接管是另一个需设计、测试并核对政策的后续功能，不能当作当前商店版已支持。

## 目标与名称

让用户能够找到、信任并顺利使用一款开源下载管理工具：把有权获取的网页文件、磁力任务和支持的视频来源集中管理。优先做好安装、第一次下载和失败恢复，再扩大平台与传播。

- 中文现用名：闪电全能下载；英文描述性名称暂用 **Shandian Download Manager**。README 两种语言都显示这组名称；应用名和仓库地址未改。
- 「闪电下载」已有其他产品使用，「Lightning」也存在下载管理产品。搜索结果不等于商标检索；发布新品牌、注册域名或商标前需进一步核查。保持拼音品牌与品类词组合，方便输入、辨认和搜索。
- 当前公开稳定版以 GitHub Release 为准；Mac 版界面目前为简体中文，Windows 正在开发，不能宣传为已正式支持。
- 衡量路径：仓库访问 → 安装包下载 → 独立完成首次下载 → 重复使用与推荐。Star、下载次数与活跃用户不是同一个指标。

## 1. 安装与信任（最高优先级）

- [x] 安装器检查附件地址、所选附件的 SHA-256（发布方提供时）、应用标识、必要文件和签名结构；替换失败尝试恢复旧版。已用模拟环境测试并随 0.18.23 发布。
- [ ] 在干净 Mac 系统验证安装、更新、卸载和 Apple Silicon / Intel 包；核实签名、公证费用及账号条件，再单独决定公证和公开发布。2026-11-03 本机未发现可用的 Developer ID Application 签名身份；这不证明账号没有相应会员资格。
- [ ] 无终端用户可以理解下载入口；开发版、正式版、安装提示与 README 一致。
- [ ] 明确隐私与依赖：浏览器权限、第三方站点、PikPak、代理和 ffmpeg 的行为，核对实现后发布准确说明。

完成标准：新用户不需开发者协助，按当前官方说明能安装并完成一次下载；记录卡点、系统版本和失败原因。

## 2. 浏览器扩展商店安装

目标：普通用户在 Edge Add-ons 或 Chrome Web Store 搜索并点击安装，不开启开发者模式；保留开发者模式作为上架前和开发测试的临时方案。

- [x] 初查当前权限、数据流和固定扩展 ID，见 [浏览器扩展上架核查](BROWSER_EXTENSION_STORE.md)。
- [x] 已选择保留现有完整版、另做商店版。独立原型通过右键发送常见文件直链，不扫描网页、不读取 Cookie、不自动接管浏览器下载；自动化测试及本机 Edge 开发版右键发送实测通过，尚未验证商店安装。
- [ ] 逐路径评估商店版是否符合商店内容政策；当前原型只作准备，不保证审核通过。自动接管需另行设计并验证，不得让现有下载丢失。
- [ ] 逐项验证权限的必要性、可选授权和数据流；Edge 商店版隐私政策已公开、后台用途及数据声明已填写，最终发布代码仍需核对。
- [x] Edge 0.1.1 已提交审核，后台显示 In review；通过审核前不能宣称已上架。Chrome 0.1.1 已提交审核，后台显示 Pending review。
- [ ] 取得实际 ID 后，在本机网关中只加入明确可信的对应来源，分别验证 Chrome / Edge 商店版与已有本地版的接管、回退、站点权限、更新和升级路径。不要放宽为任意扩展或网页来源。
- [x] Edge 中英文描述、图标、隐私政策链接、权限理由及审核说明已提交；兼容桌面版本 0.18.23 已公开。真实商店安装与展示仍待验证。
- [ ] 审核通过并正式上架后，更新应用内安装入口、README 和演示；验证商店搜索、安装与自动更新。未上架前不写「可在商店安装」。

Edge 官方文档称 Edge 扩展项目注册无费用，Chrome 官方文档称开发者注册需一次性费用；具体账号状态、费用及付款以对应后台为准。公开上架、付费和账户变更须取得针对具体内容与影响的授权。

- [x] 本地开发版改进下载错误提示；云盘创建中断恢复、安装替换回滚和部分下载包完整性检查有自动化测试。

完成标准：任务状态、实际文件和错误提示一致；失败时原文件及恢复路径清楚；问题可复现、有记录。
